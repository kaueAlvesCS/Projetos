## 🎓 Projetos Interdisciplinares (FECAP)

Trabalhos práticos desenvolvidos em grupo durante a graduação em Ciência da Computação, com foco em simular o desenvolvimento de soluções para o mercado e treino de tecnologias.

### [Plataforma Web para Eventos (Projeto 4)](https://github.com/2026-2-NCC2/Projeto4)
*   **Descrição:** Desenvolvimento de uma plataforma web voltada para conectar organizadores de eventos e fornecedores para a criação de eventos e vendas de tickets. É um projeto interdisciplinar com duração de 5 a 6 meses. O trabalho está estruturado com divisão de responsabilidades, onde atuo em conjunto com o meu grupo para o desenvolvimento e progresso do projeto. Projeto parceiro da empresa TrocaTicket.
*   **Tecnologias:** JavaScript, Node.js, React, HTML, CSS e Banco de Dados.
*   **Status:** 🚧 Em Desenvolvimento.

### [Axis Defense](https://github.com/2026-1-NCC1/Projeto5)
*   **Descrição:** Projeto desenvolvimento no primeiro semestre de 2026. Objetivo era criar um jogo simples e inovador para o mercado de jogos usando a ferramenta de software Unity como base. O projeto surgiu com a intenção de aplicar conceitos de programação em lógica e trabalho em equipe para seu desenvolvimento. Atualmente o projeto está concluído e você pode testá-lo via link. Projeto parceiro da empresa Igg Games.
*   **Tecnologias:** C# com metodologia em POO e Unity.
*   **Status:** ✔️ Concluído.

## 💻 Projetos Pessoais e de Estudo

Espaço reservado para projetos autônomos que desenvolvo para explorar novas tecnologias, aplicar lógicas de programação e estruturar aplicações. 

### [CoreBank API](https://github.com/kaueAlvesCS/API-CoreBank/tree/main)
*   **Descrição:** O CoreBank API é um projeto criado para fins puramente práticos e de estudo. A ideia principal é construir uma API do zero em dupla, superando as dificuldades com ecossistema web e praticando a integração real entre código e banco de dados. Projeto de desenvolvimento com meu amigo Nicolas.
*   **Tecnologias:** Html, Css, Javascript, Node.js, SQL.
*   **Status:** 🚧 Em Desenvolvimento
*   **Objetivo de Aprendizado:** Aplicar conceitos aprendidos na faculdade para um projeto simples de mercado.
